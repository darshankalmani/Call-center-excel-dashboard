# Call-center-excel-dashboard

## About the Project

This project is an Excel dashboard built using a call center dataset. The aim of the project is to analyze call center performance by tracking key metrics such as call volume, customer satisfaction, purchase amount, and call duration.

The dashboard provides an interactive view of the data using Pivot Tables, Pivot Charts, and Slicers, making it easier to explore performance across different time periods and categories.

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting

---

## Dataset

The dataset contains information related to customer support calls, including:

- Call Number
- Customer ID
- Representative
- Call Duration
- Date of Call
- Purchase Amount
- Satisfaction Rating
- Financial Year
- Day of the Week
- Customer Gender
- Customer Age
- Customer City

---

## Dashboard Features

The dashboard includes the following insights:

- Total number of calls
- Total purchase amount
- Total call duration
- Average customer satisfaction rating
- Number of 5-star rated calls
- Monthly call distribution
- Call distribution by day of the week
- Interactive filtering using slicers

## How to Use

1. Download the `portfolio project.xlsx` file.
2. Open it in Microsoft Excel.
3. Go to the dashboard or pivot sheet.
4. Use the available slicers to filter the data and explore different insights.
5. Review the charts and summary metrics to understand call center performance.
